# 🧠 Clinical Prediction Portfolio

Este repositório reúne uma coleção de notebooks focados em **predição clínica utilizando aprendizado de máquina**, com o objetivo de desenvolver, testar e consolidar expertise em modelagem preditiva aplicada à saúde.

Trata-se de um portfólio técnico voltado para prática estruturada, experimentação metodológica e aprimoramento contínuo em ciência de dados clínica.

---

## 📌 Objetivos

- Desenvolver modelos de classificação aplicados a problemas clínicos
- Implementar boas práticas metodológicas
- Explorar diferentes algoritmos e estratégias de validação
- Comparar desempenho com rigor estatístico
- Documentar processos de forma reprodutível

Este repositório prioriza **estrutura, clareza e consistência científica**, não apenas desempenho de métricas.

---

## 🗂 Estrutura da Pasta

Cada notebook aborda um problema específico de predição clínica, podendo conter:

- Análise exploratória dos dados (EDA)
- Preparação e tratamento de variáveis
- Separação em treino, validação e teste
- Validação cruzada estratificada
- Comparação de múltiplos modelos
- Avaliação em conjunto de teste independente
- Cálculo de intervalos de confiança via bootstrap
- Visualizações (ROC, Precision-Recall, matriz de confusão)
- Interpretação do modelo quando aplicável

---

## 🧪 Modelos Explorados

Entre os algoritmos utilizados nos notebooks:

- Regressão Logística  
- Support Vector Machine (SVM)  
- Random Forest  
- Extra Trees  
- Gradient Boosting  
- AdaBoost  

Outros modelos podem ser adicionados conforme evolução do portfólio.

---

## 📊 Métricas Utilizadas

As avaliações priorizam métricas clinicamente relevantes, como:

- Accuracy  
- Sensibilidade (Recall)  
- Especificidade  
- Precisão  
- F1-score  
- ROC-AUC  
- PR-AUC  
- Balanced Accuracy  

Sempre que pertinente, intervalos de confiança de 95% são estimados por bootstrap.

---

## 🔬 Abordagem Metodológica

- Divisão estratificada para evitar viés de classe  
- Uso de `Pipeline` para evitar vazamento de dados  
- Comparação baseada em média ± desvio padrão na validação cruzada  
- Avaliação final em conjunto de teste independente  
- Separação clara entre fase de modelagem e fase de reporte  

O foco é manter rigor metodológico compatível com estudos científicos.
